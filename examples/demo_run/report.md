# GMV 异动归因：2020-12-15 vs 2020-12-08

> 离线演示：数据为 attribution/synthetic.py 生成的合成数据，并人为注入了「organic 渠道 70% 买家结算后流失」。数字只用于展示流程，不是 Google Merchandise Store 的真实结论。

## TL;DR

- GMV -23.1%（-$2,112），2020-12-15 vs 2020-12-08。[E3]
- 主要原因：下单转化率 CR，贡献 83% 的变化。[E3]
- 问题集中在：channel=organic（占该因子变化 119%）。[E4]

## 1. 背景与对比口径

- 当前期：2020-12-15；基准期：2020-12-08（默认上周同一天）
- 指标口径：docs/metrics/gmv.md、uv.md、conversion_rate.md、aov.md

## 2. 是否为真异动 [E1]

| 检查 | 结论 |
|---|---|
| event_mix | 各事件变化幅度一致，没有单一事件断崖 |
| event_mix_by_os | 按 os 切片后也没有发现单一事件断崖 |
| hourly | 小时分布完整，没有截断 |
| new_values_channel | channel 取值没有新增或消失 |
| new_values_device | device 取值没有新增或消失 |
| new_values_country | country 取值没有新增或消失 |
| significance [E2] | GMV 变化 -23.1%，GMV |z|=2.47，阈值 2.0 → 显著 |

**判定：real_anomaly**（置信度 high）

## 3. 因子拆解（LMDI）[E3]

| 因子 | 基准期 | 当前期 | 变化 | 对 GMV 贡献 | 贡献占比 |
|---|---|---|---|---|---|
| 访客数 UV | 5,331 | 5,393 | +1.2% | +$93 | -4% |
| 下单转化率 CR | 3.71% | 2.99% | -0.73pp | -$1,756 | 83% |
| 客单价 AOV | $46.18 | $43.68 | -5.4% | -$448 | 21% |
| 合计 | $9,144 | $7,032 | -23.1% | -$2,112 | 100% |

LMDI 残差：5.46e-12（三项贡献之和与 ΔGMV 一致）

## 4. 维度下钻（下单转化率 CR）[E4]

## 5. 结论与建议

| 发现 | 建议 | 负责方 | 验证指标 / 恢复标准 |
|---|---|---|---|
| channel=organic 的结算率变化是主因 | 排查 2020-12-15 前后该人群相关的页面改版、投放或活动变更 | 产品 / 投放 | 按天监控该人群结算率，回到基准期水平视为修复 |

## 6. 局限

- 渠道为用户首次获客媒介（traffic_source.medium），不是本次会话渠道；
- 分维度 UV 不严格可加，UV 下钻占比为近似值；
- 单日对比受随机波动影响，结论需结合连续多日趋势确认。
